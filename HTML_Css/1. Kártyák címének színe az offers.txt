1. Kártyák címének színe az offers oldalon

Feladat:

Az ingatlan kínálat oldalon a kártyák címe legyen ugyanolyan színű, mint az oldal háttérszíne.

A style.css végére:

.offers .card-title {
    color: var(--bs-body-bg);
}

Ha nincs .offers osztály az oldalon, akkor használható egyszerűbben:

.card-title {
    color: var(--bs-body-bg);
}

Vagy ha konkrét háttérszín van, például fehér:

.card-title {
    color: white;
}
2. Aktív menüpont színe és félkövérsége

Feladat:

Aktív menüpont színe: RGB(71, 71, 150)
Félkövér legyen

A style.css végére:

.navbar .nav-link.active {
    color: rgb(71, 71, 150) !important;
    font-weight: bold;
}

Ha nem Bootstrap nav-link active van, hanem például csak active:

.navbar .active {
    color: rgb(71, 71, 150) !important;
    font-weight: bold;
}

5. newad.html menü középre igazítása

Ha a menü nincs középen, keresd meg a nav részt.

Példa Bootstrap esetén:

<ul class="navbar-nav">

Legyen:

<ul class="navbar-nav mx-auto">

Vagy ha divben van:

<div class="navbar-nav mx-auto">

A mx-auto középre húzza a menüt.

Ha nem Bootstrapes megoldás van, CSS-ben:

.navbar-nav {
    margin-left: auto;
    margin-right: auto;
}
6. Dátum script hiba javítása

Hiba:

Uncaught TypeError: document.querySelector(...) is null

Ez azt jelenti:

A JavaScript olyan elemet keres, ami nincs az oldalon.

Példa hibás script:

<script>
    document.querySelector('#date').value = new Date().toISOString().split('T')[0];
</script>

De ha az input id-ja nem date, akkor null lesz.

Javítás

A dátum mezőnek legyen azonosítója:

<input type="date" id="hirdetesDatuma" class="form-control">

A script pedig ezt keresse:

<script>
    document.querySelector('#hirdetesDatuma').value =
        new Date().toISOString().split('T')[0];
</script>

Még jobb, biztonságosabb megoldás:

<script>
    const datumMezo = document.querySelector('#hirdetesDatuma');

    if (datumMezo) {
        datumMezo.value = new Date().toISOString().split('T')[0];
    }
</script>
7. Új hirdetés beszúrása az offers.html oldalra

Feladat:

A két ház után szúrj be egy újabb hirdetést.
Az adatok a lakas.txt fájlban vannak.

Az offers.html fájlban keresd meg a kártyákat.

Példa kártya:

<div class="card">
    <img src="..." class="card-img-top" alt="...">
    <div class="card-body">
        <h5 class="card-title">Ház 2022-02-24</h5>
        <p class="card-text">Leírás...</p>
        <p>Tehermentes: igen</p>
    </div>
</div>

A két ház után szúrj be egy újat a lakas.txt adataival.

Minta szerkezet:

<div class="col-md-4">
    <div class="card h-100">
        <img src="KEP_URL" class="card-img-top" alt="Lakás">
        <div class="card-body">
            <h5 class="card-title">Lakás DÁTUM</h5>
            <p class="card-text">
                LEÍRÁS
            </p>
            <p>
                <strong>Tehermentes:</strong> Igen
            </p>
        </div>
    </div>
</div>

A lakas.txt adataiból cseréld ki:

KEP_URL
DÁTUM
LEÍRÁS
Tehermentes érték
8. Új URL mező a newad.html oldalon

Feladat:

Címke: Fénykép az ingatlanról
Típus: url
Stílusa egyezzen a többi mezővel

Keresd meg a formot a newad.html oldalon, majd a többi mező közé szúrd be:

<div class="mb-3">
    <label for="kepUrl" class="form-label">
        Fénykép az ingatlanról
    </label>
    <input
        type="url"
        class="form-control"
        id="kepUrl"
        name="kepUrl"
        required
    >
</div>

Ha a többi mező nem Bootstrapes, hanem például ilyen:

<div class="form-group">

Akkor ehhez igazítsd:

<div class="form-group">
    <label for="kepUrl">Fénykép az ingatlanról</label>
    <input type="url" id="kepUrl" name="kepUrl">
</div>
